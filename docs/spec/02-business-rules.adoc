= Die Regeln stehen als eine nummerierte Liste in EARS-Syntax

Jede Regel ist genau eine Aussage in einem EARS-Muster, auf Deutsch formuliert:

[horizontal]
Ubiquitär:: „Das System soll …“
Ereignis:: „Wenn <Auslöser>, soll das System …“
Zustand:: „Während <Zustand>, soll das System …“
Unerwünscht:: „Falls <Bedingung>, dann soll das System …“
Optional:: „Wo <Merkmal>, soll das System …“

Die Nummern sind nach Themen gruppiert; Lücken lassen Platz für spätere Regeln.
Eine Regel ist der Vertrag, die Gherkin-Szenarien in <<acceptance>> sind der Beweis.

== Bewertung (BR-40 bis BR-46)

Die Regeln BR-40 bis BR-43 geben die offiziellen Prüfungsregeln wieder.
Eine `pickQuestion` mit genau einer korrekten Option ist eine A-Frage, mit mehreren eine P-Frage; eine `categoryQuestion` ist eine K-Frage.
`p` ist die Punktzahl der Frage (Attribut `points`).

[cols="1,6,2"]
|===
|ID |Regel |Quelle

|[[BR-40]]BR-40
|Das System soll eine A-Frage mit `p` Punkten bewerten, wenn genau die korrekte Option gewählt ist, und sonst mit 0 Punkten.
|Prüfungsregeln

|[[BR-41]]BR-41
|Das System soll eine P-Frage mit `max(0, p × (r − f) / n)` bewerten, wobei `n` die Zahl der korrekten Optionen, `r` die Zahl der gewählten korrekten und `f` die Zahl der gewählten falschen Optionen ist; falls mehr als `n` Optionen gewählt sind, dann mit 0 Punkten.
|Prüfungsregeln

|[[BR-42]]BR-42
|Das System soll eine K-Frage mit `max(0, p × (r − f) / n)` bewerten, wobei `n` die Zahl der Aussagen, `r` die Zahl der richtig und `f` die Zahl der falsch zugeordneten Aussagen ist; offen gelassene Aussagen zählen weder als `r` noch als `f`.
|Prüfungsregeln

|[[BR-43]]BR-43
|Das System soll eine Prüfung als bestanden werten, wenn die Summe der erreichten Punkte mindestens 60 % der Summe der erreichbaren Punkte beträgt.
|Prüfungsregeln

|[[BR-44]]BR-44
|Wenn ein Kandidat eine Prüfung abgibt, soll das System erreichte Punkte, erreichbare Punkte, Prozentwert und „bestanden/nicht bestanden“ zeigen und zu jeder Frage die erreichten Punkte, die korrekte Lösung und die Erklärung, falls vorhanden.
|PRD M3, Runde 8

|[[BR-45]]BR-45
|Wenn ein Kandidat eine Prüfung abgibt, soll das System den Abschlusszähler jeder Version in dieser Prüfung um 1 erhöhen.
|PRD R9, SC2

|[[BR-46]]BR-46
|Das System soll Punkte als exakte Brüche rechnen und erst bei der Anzeige auf zwei Nachkommastellen runden.
|Spec-Entscheidung
|===
